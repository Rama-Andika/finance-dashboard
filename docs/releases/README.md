# Catatan rilis untuk finance

Folder ini berisi satu berkas per rilis **MINOR atau MAJOR**: `vX.Y.Z.md`, dalam bahasa Indonesia, untuk tim finance. Berkasnya dibuat sebagai kerangka oleh `npm run release -- notes`, diisi manusia, lalu di-commit sebelum rilis. Bagian "Perubahan angka" wajib terisi (tulis juga bila tidak ada angka yang berubah). Rilis PATCH tidak perlu catatan.

Cara merilis: `docs/release-deploy-guide.html` (bagian E dan F).
